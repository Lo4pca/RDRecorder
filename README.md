# RDRecorder

**RDRecorder** 是一个为游戏《Rhythm Doctor》开发的 BepInEx 5 插件，提供录制、播放和离线渲染关卡视频的功能。它允许您以任意帧率录制无声音的游戏画面，单独录制关卡音频，以及使用预录制的视频替代实时渲染的画面进行播放。

## 功能概览

- **视频录制**：以自定义 FPS（默认 60）录制游戏关卡画面，输出为 MP4 文件。录制期间游戏将自动静音，并模拟目标帧率的时间步长，确保画面流畅无卡顿。
- **音频录制**：单独录制关卡音乐和打击音效，输出为 M4A（AAC）文件。录制时会禁用不必要的视觉事件，以减少性能开销。
- **视频播放**：将之前录制的 MP4 视频叠加在游戏画面上播放，替代实时渲染。视频会与关卡节奏同步，适用于演示或测试。

> **注意**：只能录制模拟的window dance关卡。

## 快速使用

### 安装
1. 将 `RDRecorder.dll` 放入游戏的 `BepInEx/plugins` 文件夹。
2. 确保系统已安装 [FFmpeg](https://ffmpeg.org/download.html)，并将 `ffmpeg.exe` 放置在系统 PATH 中（用于编码视频/音频）。

### 配置
- 默认按下 **F2** 打开/关闭配置面板。
- 在面板中设置目标 FPS 和输出文件夹。
- 快捷键可在 `BepInEx/config/com.modding.rdrecorder.cfg` 中自定义。

### 录制视频
1. 按下 **F3** 或点击“Start Recording”按钮（需在空闲状态）。
2. 加载任意关卡，录制将自动开始（在 `PlaySong` 事件触发时）。
3. 关卡结束时（显示 Rank 评分），录制自动停止，MP4 文件保存在输出文件夹。

> **注意**：录制期间游戏会变得非常缓慢（逐帧计算），这是正常现象。视频播放速度将保持目标 FPS。

### 录制音频
1. 按下 **F5** 或点击“Record Audio”按钮。
2. 加载关卡，音频录制自动开始。
3. 关卡结束时自动停止，输出 M4A 文件。

### 播放视频
1. 按下 **F4** 或点击“Play Recordings”按钮。
2. 在弹出的文件选择对话框中选取一个 MP4 文件。
3. 加载关卡，视频将在 `PlaySong` 事件触发时开始播放。
4. 关卡结束时播放自动停止。

> **提示**：若视频与音乐不同步，请停止播放并重新加载关卡。

## 默认快捷键

| 按键 | 功能 |
|------|------|
| `F2` | 打开/关闭配置面板 |
| `F3` | 开始/停止视频录制 |
| `F4` | 选择并播放/停止视频（需先选文件） |
| `F5` | 开始/停止音频录制 |

所有快捷键均可通过配置文件修改。

## 文件输出

- 视频：`输出文件夹/关卡名_时间戳.mp4`
- 音频：`输出文件夹/关卡名_时间戳.m4a`

文件名会自动从关卡元数据（歌曲名、艺术家、作者）生成。
